# WebPlatform Social Login

Secure Google, Facebook, LinkedIn, Microsoft, and Apple sign-in for WordPress and WooCommerce.

## Install

Create or download the plugin release ZIP, upload it in WordPress under Plugins > Add New > Upload Plugin, activate it, and open Settings > WebPlatform Social Login.

Configure only the identity providers you need. The settings screen shows the callback URL, scopes, and provider-specific configuration required for the current site.

## WordPress 7.1 validation

Before changing the WordPress.org `Tested up to` value to 7.1, complete the compatibility checklist in `docs/wordpress-7.1-validation.md` on WordPress 7.1 RC/final and run WordPress Plugin Check. Keep `Tested up to: 7.0` until that validation passes.
